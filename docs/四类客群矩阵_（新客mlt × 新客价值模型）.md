# 四类客群矩阵

> 数据来源：《两模型交叉效果评估报告（新客mlt × 新客价值模型）》（2026-09-01）与其底层数据重算。四类客群按两模型现行接纳线（均 ≤ C 档）划分的四象限，占比/漏斗/风险/收入均为 Train 双分样本口径（407,134 笔，整体 3M30+ 13.01%）；OOT（129,382 笔）仅作风险验证。通过率/成交率/收入/盈余由 res 原始数据按报告口径重算（duedate 标签以 sample 文件为准，同管线），并已与交叉 Excel 逐格核对一致。

- 横轴：**风险低 → 风险高**（mlt 分）
- 纵轴：**价值低 → 价值高**（价值分）
- 分界线：两模型现行接纳线（≤ C 档）；价值 ≤ C = 价值好（低分高价值）

## 价值好 × 风险好（双低：mlt ≤ C 且价值 ≤ C）

### 稳健经营型优质客

**人群标签：** 收入稳现金流稳｜用信成熟｜履约稳健｜高额度诉求

**经营策略：** 重点经营｜提额候选池（风险由 mlt 把关、额度由价值支撑）｜3000-5000 优质 MACC / LACC / LOC

| 样本量（Train 双分样本）      |         66,565 | —                   |
| 申请通过率                    |         32.44% | 四类最高            |
| 自动/人工通过率               | 16.58%/15.86%  | 自动、人工均最高    |
| 通过后成交率                  |         81.28% | 稳定成交            |
| 3M30+ 笔数逾期率（Train）     |          6.05% | 四类最低            |
| 3M30+ 笔数逾期率（OOT 验证）  |          7.57% | OOT 同样最低        |
| 3M30+ 金额逾期率（Train）     |          5.31% | 四类最低            |

**结论：** 两模型共识的"低风险 × 高价值"核心客群——风险四类最低（6.05%，整体 13.01% 的一半不到）、审批通过率四类最高、收支为正。是提额/重点经营的第一候选池（双低象限，AND 组合的接纳段即这批人）。

## 价值好 × 风险差（仅价值低：价值 ≤ C 且 mlt > C）——错配客群

### 高薪高波动型周转客

**人群标签：** 纸面富裕｜现金过山车｜高支出高波动｜周转需求强｜高额度诉求

**经营策略：** 短周期小额承接｜EWA / 超短期产品（不作为提额对象，必须由 mlt 把关）

**人群标签：** 现金告急｜收支失衡｜还款乏力｜高危边缘客

**经营策略：** 原则上不重点承接｜限额 / 提价 / 人工审核 / 谨慎准入

## 整体结论（与交叉评估报告一致）

1. **两模型互不冗余、不做分数融合**：Train 上 Pearson 相关 0.5799（Spearman 0.6230），各组合分的 AUC/KS 均不高于 mlt 单模型分——价值模型以规则方式使用，不并入打分。
2. **AND 组合（mlt ≤ C 且价值 ≤ C）＝双低象限＝稳健经营型优质客**：接纳率 40.00% → 16.35%，接纳风险 7.40% → 6.05%（OOT 7.57%）；降险主要来自把"仅 mlt 低"（9.48%）转拒。
3. **价值模型不可单独上线**：仅价值低象限（3.65%）3M30+ 14.42%，是价值模型接纳段内的高风险盲区，必须由 mlt 把关。
4. **四类客群的处置优先级**：双低（稳健经营型）优先经营/提额 → 仅 mlt 低（低收入克制型）低额验证 → 仅价值低（高薪高波动型）短周期谨慎承接 → 双高（现金流脆弱型）风控优先。
