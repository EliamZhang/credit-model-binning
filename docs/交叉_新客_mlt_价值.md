# 两模型交叉效果评估报告（新客 mlt × 新客价值模型）

> 本报告评估新客 mlt 主风险模型分（`score_new_mlt`）与新客价值模型分（`score_new_worthiness`）交叉使用的效果，由 `scr/_gen_new_reports.py` 从 `binning_new_cross_strategy_report_20260908.xlsx`（matrix）读取数值生成（Excel 数值与 Excel 逐项一致；三章矩阵内收入 4 指标 total_income/total_expenses/gross_surplus/net_surplus 平均数由 `res/new_application_info.csv` 重算（gross_surplus/net_surplus 另附剔除 <0 样本后与成交样本两版口径，成交 = status 属 Active_Account/Closed/Blocked，同漏斗定义），分档与矩阵逐格核对一致），与 Excel 逐项一致。两模型均按各自已评审的 7 档最终分档（高分高风险方向）参与分析（方案见附录）。
>
> 分析样本为同时存在两个模型分的完成申请 536,516 笔（占 579,100 笔完成申请的 92.65%），按 Train（2024-01—2025-10）/ OOT（2025-11—2026-05）切分，OOT 仅用于验证。两模型分数缺失口径：mlt 缺失 42,575 笔（7.35%，含无银行交易数据人群的 −1.0 兜底分置空，2026-09-01 用户确认）、价值模型缺失 40,974 笔（7.08%，无银行交易数据人群），双分样本即两模型分数交集。
>
> **一句话结论：不做分数融合；价值模型的正确用法是二维规则——AND 组合（new_mlt ≤ C 档且新客价值模型 ≤ C 档）可把接纳风险压低到 6.05%（new_mlt 单模型接纳 7.40%；当前组合点接纳率 16.35%），而"仅价值低"的错配客群（Train 3.65%、3M30+ 14.42%）必须由 new_mlt 把关拦截。**

## 一、结论摘要

1. **两模型中等相关、互不冗余**：Train 上 Pearson 相关 0.5799、Spearman 相关 0.6230、分档秩相关 0.6031。
2. **分数融合不加分**：各组合分的 Train/OOT AUC、KS 均不高于新客 mlt 单模型分（详见五）。
3. **增量信息双向存在，mlt 是主排序器**：mlt 各档内价值增量与价值各档内 mlt 增量并存，mlt 档内跨度远大于价值档内跨度（详见四）。
4. **共识人群风险梯度清晰**：对角 3M30+ 由 A-A 低风险格单调升至 G-G 高风险格（详见三）。
5. **AND 规则交叉是唯一有效的交叉方式**：接纳风险 new_mlt 单模型 7.40% → AND 组合 6.05%（OOT 7.57%），接纳率 40.00% → 16.35%；OR 组合无增益（详见六）。
6. **价值模型单独使用有高风险盲区**："仅价值低"象限（新客价值模型 ≤ C 但 new_mlt > C）Train 3.65%、3M30+ 14.42%——即"价值好 & 风险差"错配客群，价值模型单独决策会把这批高风险人群放进接纳段。

## 二、数据与口径

- **样本**：完成申请 579,100 笔中同时存在两个模型分的 536,516 笔（92.65%）；mlt 分缺失 42,575 笔（7.35%）、价值分缺失 40,974 笔（7.08%），双分样本即两模型分数交集。
- **切分**：双分样本 407,134 / 129,382。两模型单模型策略通过率在双分口径下重算，与各自分箱报告略有差异（剔除对方模型缺失分样本所致）。
- **分档**：两模型均使用各自报告已评审的 7 档方案（见附录边界）。档位序 1–7 对应风险从低到高。
- **风险指标**：沿用笔数违约口径，1M30+/3M30+ 笔数逾期率为主要观察指标，金额逾期率同步输出；矩阵格的 Lift = 格逾期率 ÷ 该样本组整体逾期率；样本量不足 100 的格风险类指标显示 —。
- **价值语义**：价值模型分为"低分 = 高价值"（分数越低，利息贡献越高，见 docs/价值评估_新客_0520.html）。因此价值档 A（最低分）同时是"高价值 + 低风险"档；下文"价值 ≤ C"即"价值好（低分）人群"。

## 七、落地建议

1. **不做分数融合**：价值模型不以"提升打分能力"的理由并入 mlt 分数，以规则方式使用。
2. **降险优先选 AND 组合**：接纳风险 7.40% → 6.05%（OOT 7.57%），接纳率 16.35%；业务需先确认流量代价是否可接受，再在 AND 网格（六（二））中按风险目标选点。
3. **流量敏感场景优先评估边界档加严**：mlt 现行策略整体不动，仅对 mlt 边界档（如 C 档）内价值 ≥ D 档的人群转人工审核，用较小流量代价获取大部分降险收益。
4. **价值模型不要单独上线**：其接纳段内混有 3.65% 的实际高风险人群（3M30+ 14.42%）；若必须单独上线，需在 C 档以内叠加 mlt 加严条件。
5. **提额/经营场景用"双低象限"**：候选人群为双低象限（new_mlt ≤ C 且 new_wth ≤ C），风险由 new_mlt 档位把关、额度由价值（收入代理）支撑；注意排除"仅价值低"象限的错配人群。
6. **上线后按月监控**：组合段风险、两模型分档分布（PSI）、强分歧格占比，重点关注双高格与仅价值低象限的风险漂移。
