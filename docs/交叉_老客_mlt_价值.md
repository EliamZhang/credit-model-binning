# 两模型交叉效果评估报告（老客 mlt × 价值模型）

> 本报告评估老客 mlt 主风险模型分（`score_mlt`）与价值模型分（`score_worthiness`）交叉使用的效果，由 `scr/_gen_new_reports.py` 从 `binning_cross_strategy_report_20260908.xlsx`（matrix）读取数值生成（Excel 数值与 Excel 逐项一致；三章矩阵内收入 4 指标 total_income/total_expenses/gross_surplus/net_surplus 平均数由 `res/old_application_info.csv` 重算（gross_surplus/net_surplus 另附剔除 <0 样本后与成交样本两版口径，成交 = status 属 Active_Account/Closed/Blocked，同漏斗定义），分档与矩阵逐格核对一致），与 Excel 逐项一致。两模型均按各自已评审的 7 档最终分档（高分高风险方向）参与分析（方案见附录）。
>
> 分析样本为同时存在两个模型分的完成申请 306,149 笔（占 328,063 笔完成申请的 93.32%），按 Train（2024-01—2025-10）/ OOT（2025-11—2026-05）切分，OOT 仅用于验证。两模型分数缺失口径：mlt 缺失 0 笔（0.00%）、价值模型缺失 21,914 笔（6.68%，无银行交易数据人群），双分样本即两模型分数交集。
>
> **一句话结论：不做分数融合；价值模型的正确用法是二维规则——AND 组合（mlt ≤ E 档且价值模型 ≤ C 档）可把接纳风险压低到 5.53%（mlt 单模型接纳 6.80%；当前组合点接纳率 36.47%），而"仅价值低"的错配客群（Train 3.52%、3M30+ 20.59%）必须由 mlt 把关拦截。**

## 一、结论摘要

1. **两模型中等相关、互不冗余**：Train 上 Pearson 相关 0.5938、Spearman 相关 0.6069、分档秩相关 0.5882。
2. **分数融合不加分**：各组合分的 Train/OOT AUC、KS 均不高于老客 mlt 单模型分（详见五）。
3. **增量信息双向存在，mlt 是主排序器**：mlt 各档内价值增量与价值各档内 mlt 增量并存，mlt 档内跨度远大于价值档内跨度（详见四）。
4. **共识人群风险梯度清晰**：对角 3M30+ 由 A-A 低风险格单调升至 G-G 高风险格（详见三）。
5. **AND 规则交叉是唯一有效的交叉方式**：接纳风险 mlt 单模型 6.80% → AND 组合 5.53%（OOT 5.80%），接纳率 70.30% → 36.47%；OR 组合无增益（详见六）。
6. **价值模型单独使用有高风险盲区**："仅价值低"象限（价值模型 ≤ C 但 mlt > E）Train 3.52%、3M30+ 20.59%——即"价值好 & 风险差"错配客群，价值模型单独决策会把这批高风险人群放进接纳段。

## 二、数据与口径

- **样本**：完成申请 328,063 笔中同时存在两个模型分的 306,149 笔（93.32%）；mlt 分缺失 0 笔（0.00%）、价值分缺失 21,914 笔（6.68%），双分样本即两模型分数交集。
- **切分**：双分样本 241,873 / 64,276。两模型单模型策略通过率在双分口径下重算，与各自分箱报告略有差异（剔除对方模型缺失分样本所致）。
- **分档**：两模型均使用各自报告已评审的 7 档方案（见附录边界）。档位序 1–7 对应风险从低到高。
- **风险指标**：沿用笔数违约口径，1M30+/3M30+ 笔数逾期率为主要观察指标，金额逾期率同步输出；矩阵格的 Lift = 格逾期率 ÷ 该样本组整体逾期率；样本量不足 100 的格风险类指标显示 —。
- **价值语义**：价值模型分为"低分 = 高价值"（分数越低，利息贡献越高）。因此价值档 A（最低分）同时是"高价值 + 低风险"档；下文"价值 ≤ C"即"价值好（低分）人群"。

### （三）现行接纳阈值的四象限人群

按 mlt 接纳线（≤E）与价值模型接纳线（≤C）划分：双低 = 低风险 × 高价值（优先经营）、仅 mlt 低 = 低风险 × 低价值（收益验证）、仅价值低 = 高价值 × 高风险（谨慎经营）、双高 = 高风险 × 低价值（优先风险控制）。

| 样本组 | 象限 | 样本量 | 占比 | 1M30+ | 3M30+ |

- **仅价值低象限**即"价值好 & 风险差"错配客群：价值模型单独决策会把它们放进接纳段，是其单模型策略最危险的部分，mlt 恰好能拦住；该象限适合"谨慎经营"（短期、小额产品）而非直接提额。

## 七、落地建议

1. **不做分数融合**：价值模型不以"提升打分能力"的理由并入 mlt 分数，以规则方式使用。
2. **降险优先选 AND 组合**：接纳风险 6.80% → 5.53%（OOT 5.80%），接纳率 36.47%；业务需先确认流量代价是否可接受，再在 AND 网格（六（二））中按风险目标选点。
3. **流量敏感场景优先评估边界档加严**：mlt 现行策略整体不动，仅对 mlt 边界档（如 C 档）内价值 ≥ D 档的人群转人工审核，用较小流量代价获取大部分降险收益。
4. **价值模型不要单独上线**：其接纳段内混有 3.52% 的实际高风险人群（3M30+ 20.59%）；若必须单独上线，需在 C 档以内叠加 mlt 加严条件。
5. **提额/经营场景用"双低象限"**：候选人群为双低象限（mlt ≤ E 且 wth ≤ C），风险由 mlt 档位把关、额度由价值（收入代理）支撑；注意排除"仅价值低"象限的错配人群。
6. **上线后按月监控**：组合段风险、两模型分档分布（PSI）、强分歧格占比，重点关注双高格与仅价值低象限的风险漂移。
